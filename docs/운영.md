## 1. 로컬에서 보기

```
cd 이 폴더
python -m http.server 8765
```

크롬에서 `http://127.0.0.1:8765/seoul_vworld.html`. 끝나면 서버 창에서 Ctrl+C.

- 인터넷이 필요하다. 파일 더블클릭(`file://`)은 인증이 실패할 수 있다.
- 처음 열면 프리로드("서울 3D 건물 불러오는 중")가 끝나야 재생이 시작된다. 시나리오를 바꿀 때는 다시 하지 않는다.
- 개발 중에는 `seoul_vworld.html` 안의 값만 바꿔도 새로 고침하면 반영된다. 파일이 3.6MB라 에디터가 느릴 수 있다(§6).

## 2. 서버에 올리기

대회 서버(카페24 호스팅)에 **파일 하나**를 올린다.

| 항목 | 값 |
|---|---|
| 주소 | https://educnp.mycafe24.com/team6/ (**대회 종료 후 내려감.** 지금은 "서비스 완료 안내" 페이지. 아래는 대회 때 쓴 방식의 기록이다) |
| 올리는 곳 | 서버의 `/www/team6/index.html` (FTP 일반 접속, 포트 21) |
| 올리는 파일 | `seoul_vworld.html`(§3대로 API 키를 넣은 것)을 `index.html`로 이름만 바꿔서 |
| 접속 정보 | 대회 운영 측이 준 것을 쓴다. **이 저장소에는 적지 않는다** |

절차

1. 올릴 파일을 따로 만든 폴더(예: 바탕 화면의 `team6\`)에 `index.html`로 복사한다. 작업 폴더 전체를 올리지 않는다(`.py` 등 서버 파일이 섞이면 안 된다)
2. 서버의 현재 `index.html`을 먼저 내려받아 백업한다
3. `/www/team6/` **안에만** `index.html`을 덮어쓴다. 다른 조 폴더(team1~team8 중 team6이 아닌 곳)와 `/www/team6/` 밖은 건드리지 않는다
4. 업로드한 크기가 원본과 같은지 확인한다(최종본 3,675,894바이트)
5. 주소를 열어 지도·모델이 뜨는지, 탭 이름이 새 것인지 확인한다. 옛 화면이 보이면 `Ctrl+F5`

**되돌리기**: `archive/`에서 원하는 버전을 `index.html`로 복사해 같은 방법으로 올린다. 11/5 최종 수정 직전은 `archive/seoul_vworld.v_before_final_fix.html`.

- `seoul_vworld.html` 안의 `VWORLD_KEY` 상수에 브이월드 API 키를 넣는다. 활용 API는 "3D 지도 API"다

## 4. 단축키와 진단

| 키 | 동작 |
|---|---|
| `Space` | 재생·일시정지 |
| `D` | 진단 패널(스크립트 로드·모델 로드 로그, 지면 높이 보정) 열기·닫기 |
| `F` | 화면 오른쪽 아래에 fps 표시 |

- 지도가 안 뜨면: `D`로 진단 패널을 열어 "[실패]" 줄을 본다. 대부분 인터넷 문제나 API 설정 문제다
- 건물에 차량이 박히거나 떠 보이면: 진단 패널의 "지면 높이 보정(m)"을 바꾼다(기본 40). 목격자는 코드의 `WIT_DROP`(24)으로 따로 내린다
- 차량이 옆으로 가면: 주소 뒤에 `?yaw=90`, `180`, `-90`을 붙여 모델 앞 방향을 돌려 본다

## 5. 데모 영상 녹화

발표에서 영상으로 시연을 넣었다.

1. 크롬 전체 화면(F11)으로 열고 프리로드가 끝날 때까지 기다린다
2. Windows 게임 바(`Win+G`)나 OBS로 녹화한다(1920×1080, 30fps, MP4)
3. 녹화를 켠 뒤 시나리오 탭을 누르면 바로 재생된다. 결과 화면(약 4.5초)까지 찍고 멈춘다. ①은 반복되므로 10초쯤에서 끊는다
4. 다른 프로그램을 닫고 충전기를 연결한다. 렉이 심하면 다시 찍는다
5. PowerPoint 2016: 삽입 → 비디오 → 내 PC의 비디오. 재생 탭에서 반복 재생, 비디오 트리밍으로 앞부분 자르기, 전환 탭의 "다음 시간 후"로 자동 넘김

## 6. 문제가 생겼을 때

| 증상 | 확인·대응 |
|---|---|
| 화면이 비어 있다(패널도 없음) | 스크립트 문법 오류. 브라우저 콘솔의 첫 오류를 본다. 직전 `archive/` 백업으로 되돌린다 |
| 지도가 까맣다 | 인터넷, API 설정, 진단 패널 로그. 프리로드가 길 수도 있다 |
| 렉이 심하다 | `F`로 fps 확인. 다른 탭을 닫는다. 발표용 PC에서 미리 한 번 돌려 본다 |
| 서버에 올렸는데 옛 화면 | `Ctrl+F5`. 업로드 크기 확인 |
| 영상이 PPT에서 안 나온다 | MP4(H.264)인지, 발표 PC에서 미리 재생해 봤는지. 파일 → 정보 → 미디어 호환성 최적화 |
| 모델이 안 보인다 | 진단 패널의 "모델 로드 완료" 줄 확인. 실패하면 쐐기형 차체로 자동 대체된다 |

## 7. 파일을 고칠 때

- `seoul_vworld.html`은 3D 모델 두 개가 base64로 **한 줄**에 들어 있어 텍스트 에디터로 열면 느리다. 바꾸는 부분만 정규식·문자열 치환 스크립트로 고치거나, 모델이 든 줄을 건드리지 않게 주의한다
- 고치기 전에 `archive/seoul_vworld.v_이름.html`로 백업을 남긴다(이 저장소의 기존 백업 이름 규칙)
- 바꾼 뒤에는 로컬 서버로 열어 콘솔에 오류가 없는지, 세 시나리오가 재생되는지 확인한다
- 바꿨으면 서버에 올리기 전에 이 문서와 `현황.md`를 같이 고친다
