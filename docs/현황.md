## 4. 알려진 한계

- **모바일 미대응.** 패널과 지도가 PC 화면 기준이라 폰에서는 깨진다. 패널을 숨기고 애니메이션만 보여 주는 모드를 구상했으나 만들지 않았다
- **렉이 있었다.** 노트북에서 시나리오 재생 중 프레임이 떨어졌다. 지도 타일 로딩과 매 프레임 카메라 갱신이 가장 큰 원인이고, 화면 효과(흐림·그림자 애니메이션)와 불필요한 글자 갱신은 줄였다. **줄인 효과를 수치로 측정하지는 못했다**(작업 환경의 브라우저가 화면 갱신을 1초에 한 번으로 제한해서). `F` 키로 fps를 볼 수 있다
- **인터넷 필수.** 브이월드 서버를 쓰므로 오프라인에서는 지도가 뜨지 않는다. 처음 열 때 프리로드가 길다(1~2분)
- **18초 전체를 이어서 재생해 본 기록이 약하다.** 작업 중에는 장면별로 시점을 옮겨 가며 확인했다
- **실제 사용자 테스트는 하지 못했다.**
- **수치는 전부 가정.** 센서, 생체신호, 119 구조대·병원 이름도 가상이다
- 예시 웹앱을 참고한 UI의 라이선스는 확인하지 못했다
