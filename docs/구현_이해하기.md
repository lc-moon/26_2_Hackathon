# 구현 이해하기

> **코드를 처음 보는 사람, 또는 "이 애니메이션은 어떻게 만들었어요?"라는 질문에 답해야 하는 사람용.**
> 쉬운 말로 설명한다. 수치와 함수 이름은 2026-11-05 최종본(`seoul_vworld.html`) 기준.

---

## 1. 한 줄 설명

**물리 엔진이 아니라, "t초일 때 차량이 어디에 있고 화면에 무엇이 보이는가"를 계산하는 함수들로 만든 연출이다.** 3D 지도는 브이월드(안의 Cesium)가 그려 주고, 차량·선·글자·패널은 우리가 직접 올렸다.

스택: HTML + CSS + 순수 JavaScript, 단일 파일. 프레임워크, 애니메이션 라이브러리, 서버, DB 없음.

---

## 2. 전체 그림

```
시간 t (초)  ──▶  위치 함수(posBA, posBB, posBR …)  ──▶  Cesium에 차량·선 배치
   │                카메라 키프레임(KF)               ──▶  카메라 이동
   │                상태·수치 함수(phase, vitals …)   ──▶  패널·알림 글자 갱신
   └─ requestAnimationFrame 루프가 매 프레임 t를 3배속으로 늘림
```

- 위치, 고도, 상태 문구, 생체신호가 모두 **t만 넣으면 값이 나오는 함수**다. 그래서 슬라이더를 어디로 옮겨도 같은 장면이 나온다
- 재생 속도 `SPEED = 3`. 내부 시간 54초가 실제 18초에 재생된다

---

## 3. 지도와 3D (브이월드 + Cesium)

- 브이월드 3D 지도 API 3.0 스크립트 3개를 순서대로 불러 `new vw.Map()`으로 시작한다
- 브이월드는 Cesium 1.99를 안에 품고 있어서, 시작 후 지도 객체 안을 뒤져 Cesium 뷰어(`findViewer()`)를 찾아 쓴다
- 차량·선·글자는 이 뷰어에 직접 올린다
  - 차량: GLB 3D 모델을 `Cesium.Model.fromGltf`로 불러와 매 프레임 위치·방향 행렬(`modelMatrix`)을 바꾼다. 모델이 안 불러와지면 코드로 만든 쐐기형 차체(`carMesh`)가 대신 나온다
  - 선(경로, 견인 케이블): Cesium 엔티티. 위치는 `CallbackProperty`로 매 프레임 계산해서 준다
  - 이름표·목적지 글자: Cesium 라벨 대신 **HTML 요소**를 위에 띄우고 매 프레임 3D 좌표 → 화면 좌표로 위치만 맞춘다(Cesium 라벨은 흐릿해서)
- 모델은 base64 글자로 HTML 안에 넣어 한 파일로 배포한다

## 4. 움직임을 만드는 법

- **보간**: 시작점과 끝점 사이를 `t` 비율로 나눠 계산한다(lerp). 가속·감속은 부드러운 곡선(smoothstep)으로 준다
- 좌표는 사고 중심 `C`(서울시청 부근) 기준 **동·북 미터 오프셋**으로 적고 위경도로 환산한다

### 추돌과 튕김 (③·②)

| 상수 | 뜻 | 값 (C 기준 동·북 m) |
|---|---|---|
| `AI` | A의 충돌 순간 위치 | (−73, 0) |
| `BI` | B의 충돌 순간 위치 | (0, −20) |
| `AE`, `BE` | 튕겨서 멈춘 위치 | (−101, 0), (0, −48) |

A의 앞머리가 B의 옆면에 닿는 위치로 정했고, 12초부터 2.5초 동안 빠르게 튕겨 느려지며(`reb(t)`) 멈춘다. 튕기는 동안 차량이 뒤집혀 보이지 않게 방향은 고정한다.

### 견인 대형 `-[` (③)

| 상수 | 뜻 | 값 |
|---|---|---|
| `D1` | 구조차 중심에서 가로대까지 | 125m |
| `SIDE` | 가로대 반폭 | 48m |
| `ARM` | 팔 길이 | 20m |
| `HALF` | 기체 반길이 | 50m |

구조차 위치만 정해지면 `towPts()`가 케이블 → 가로대 → 두 팔 → 두 기체 자리를 계산한다. 30~36초에 두 기체가 멈춘 자리에서 이 대형 위치로 끌려가며 정렬한다.
구조차는 두 기체 위(고도 240m)를 지나간 뒤 도킹 지점에서 165m로 내려앉는다(기체와 겹치지 않게).

### 카메라

- 키프레임(`KF`)은 줌·기울기·방향을 시각별로 정하고 사이를 보간한다. 매 프레임 `camera.setView`로 직접 지정한다
- 보는 대상(`focus`)은 시나리오마다 다르다. ③은 구조차와 두 기체의 중간, ②는 신고 장면(17~25초)에서 지상 목격자에게 가까이 간다

## 5. 시나리오를 바꾸는 구조

`SCS`(시나리오 배열) 3개가 각자 이런 것을 갖는다: 차량별 위치 함수·상태 문구, 가정 시간 함수(`mt`), 타임라인 이벤트, 알림·결과 화면·큰 문구 함수, 카메라 키프레임, 패널 문구, 하단 패널 함수(`bottom0/1/2`).
`setScenario(i)`가 현재 시나리오(`SCN`)를 갈아 끼우고 재생을 처음부터 시작한다. 지도 타일은 다시 받지 않는다(프리로드는 사이트를 켤 때 한 번).

---

## 6. 패널 (119 상황실 화면)

- `updatePanels(t)`가 약 0.14초마다 값을 갱신한다(글자가 바뀔 때만 화면에 쓴다)
- **탑승자 생체신호**는 수식이다: 추돌 순간(12초) 급상승했다가 시간이 지나며 안정(`stress()`, `vitals()`). 시나리오 ②의 B-1만 별도 함수로 8분 시점에 심정지가 되고 심전도가 평평해진다
- **심전도**는 캔버스에 직접 그린다. 한 박동의 P·QRS·T 파형을 가우시안 합으로 만들고 심박수에 맞춰 이어 붙인다
- **구조 우선순위 번호**는 위험도 점수로 매 갱신마다 정렬한다
- **거리·도달 시간**은 3D 직선 거리(수평+높이)를 계산하고, 시간은 가정 시간 함수에서 가져온다

---

## 7. 강조 효과

CSS 애니메이션과 몇 개의 겹침 요소로 만든다: 추돌 섬광(`#flash`), 화면 흔들림(`body.quake`), 중앙 큰 문구(`#boom`), 위급 시 붉은 테두리(`#vig`), 위험 카드 깜빡임, ② 시계 "골든타임 초과"(`.clock.late`).
그림자·필터를 계속 바꾸는 애니메이션은 비싸서 투명도만 바꾸는 방식으로 교체했다.

---

## 8. 화면 크기 맞추기

모든 길이를 `calc(Npx * var(--k))`로 쓰고, `fitUI()`가 창 크기에서 배율 `--k`를 정한다(1333×833 이하 1, 1920×1080 약 1.3, 최대 1.8). 폭이 좁으면(`compact`) 탭 보조 문구를 숨긴다.

---

## 9. 프리로드

`prewarm()`이 재생 전에 시작 지점 주위를 돌며 건물 타일을 미리 받는다(최소 6초, 최대 45초, 로딩이 1.5초 안정되면 종료). 끝나면 평시 시나리오가 자동 재생된다.

## 10. 자주 바꾸는 값

| 값 | 위치 | 뜻 |
|---|---|---|
| `SPEED` | 재생 루프 | 재생 배속(3). 1이면 54초 |
| `T_N` | 시나리오 ① | 평시 길이(36초) |
| `BASE` | 시나리오 정의 앞 | 지면 높이 보정(40m). 진단 패널에서도 바꾼다 |
| `WIT_H`, `WIT_DROP` | 목격자 | 키 28m, 지면으로 내리는 값 24m |
| `MODEL_YAW` | 모델 | 차량 앞 방향 보정. `?yaw=` |
| `QUALITY_TUNE` | 화질 | `true`면 고화질(무거움). 기본 `false` |
| 결과 화면 유지 | 재생 루프 | ②·③은 4.5초 보여 준 뒤 반복 |

## 11. 겪은 문제와 교훈 (반복하지 말 것)

1. 전역 `const $`를 만들면 브이월드의 jQuery `$`를 덮어써 오류가 난다 → 도우미 이름은 `byId`
2. Cesium 엔티티의 상수 속성(위치·방향·재질)을 매 프레임 바꾸면 도형이 계속 재생성되어 **재생 중에 안 보이고 멈추면 보인다** → `CallbackProperty` 또는 `modelMatrix`를 쓴다
3. 모델 방향은 작업 환경에서 렌더링한 결과와 실제 브이월드 화면이 달랐다 → 실제 화면에서 확인하고 `?yaw=`로 조정
4. 주석을 코드와 같은 줄 끝에 달면 뒤 코드가 주석이 된다(재생 루프가 멈춤) → 주석은 별도 줄이나 코드 뒤에만
5. 3.6MB 한 줄 파일은 `Edit` 도구가 아니라 파이썬 치환 스크립트로 고치고, 고치기 전에 백업한다. 치환할 문자열이 정확히 한 번 나오는지 확인한다
6. 지도 위에서 매 프레임 흐려지는 CSS(`backdrop-filter`), 그림자·필터 애니메이션, 같은 글자를 매 프레임 다시 쓰기, 매 프레임 `getBoundingClientRect` 읽기는 렉의 원인이 된다
7. 작업 환경의 브라우저 창이 숨겨져 있으면 화면 갱신이 1초에 한 번으로 제한되어 프리로드가 매우 오래 걸리고 프레임 속도를 측정할 수 없다 → 속도 비교는 실제 PC에서
8. 차량이 겹쳐 보이는 문제는 눈으로 찾지 말고 회전한 직사각형 겹침 계산(SAT)에 고도 범위를 곁들여 시나리오 전체를 훑어 확인한다
9. 배포 서버에 올릴 폴더에 `.py` 같은 파일이 섞이면 안 된다 → 올릴 파일만 따로 만든 폴더에서 올린다

## 12. 테스트하는 법

로컬 서버로 열고 브라우저 콘솔에서 전역 함수를 직접 부른다(스크립트가 클래식 스크립트라 전역에서 보인다).

```
setScenario(2, false)      시나리오 ③으로 바꾸기(자동 재생 없이)
playing = false; t = 20    멈추고 20초 장면으로
dirty = true               화면 다시 그리기
updatePanels(40)           패널 값만 40초 기준으로 갱신
```

프리로드 중에는 시나리오 탭이 막혀 있으니 끝난 뒤 쓰거나 `setScenario`를 직접 부른다.
