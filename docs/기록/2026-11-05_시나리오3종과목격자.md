## 한 일

### 시나리오 구조 (백업 `archive/seoul_vworld.v_before_scn.html`, 20:45)
- 시나리오마다 차량 위치·상태 문구·타임라인·알림·결과 화면·카메라·하단 패널 함수를 갖는다
- 패널 값은 같은 코드가 시나리오 설정을 읽어 채운다. 하단 패널만 시나리오별 함수(`bottom0/1/2`)

### ① 평시
A는 중앙 구역, B는 북쪽 구역, 구조차는 남쪽에서 원을 그리며 순찰한다. 처음에는 두 기체가 같은 지점을 고도차 70m로 교차했는데 화면에서 겹쳐 보여서, 서로 겹치지 않는 구역으로 나눴다(어느 두 차량 사이도 위에서 본 거리가 233m 이상).

### ② 높이 정보·자동 신고 없음
추돌 후 자동 신고 없음 → 3분에 시민 신고 → 지상 수색 → 8분에 탑승자 B-1 심정지 → 19분에 구조 비행차량이 상공으로 접근 → 약 22분에 사망 확인. 시계는 사고 후 경과 시간을 보여 주다 4분이 넘으면 "골든타임 초과"로 바뀐다.

### 지상 목격자 (②에서만 보임)
- 후보를 Sketchfab에서 조사해 4개를 비교했다. 가볍고 재질 색만 쓰는 **Low Poly Man Taking Phone While Walking**(ROH3D, 1.5k 삼각형, CC BY 4.0)을 골랐다
- 사용자가 GLB(66kB)를 내려받았고 `assets/witness_phone.glb`로 두었다. HTML에 base64로 내장했다
- 모델 키를 28m로 키워 보이게 했고, 신고 장면(17~25초)에 카메라가 목격자에게 가까이 간다
- 파일 안 메타데이터의 원작자(tedpermana)와 다운로드 창의 표기(ROH3D)가 달랐다. 다운로드 창 기준으로 출처를 적었다

### 재생 방식
- 탭을 누르면 바로 재생. ②·③은 마지막에 결과 화면을 약 4.5초 보여 준 뒤 처음부터 다시 돈다(`holdUntil`)
- 사이트를 열면 프리로드가 끝난 뒤 ①이 자동 재생. 프리로드 중에는 탭을 눌러도 무시한다

## 문제와 해결

- **문법 오류**: 시나리오 대규모 수정 중 두 번 났다. 한 번은 배열 끝 괄호를 지워서, 한 번은 앞에서 말한 줄 끝 주석이 원인이었다. 브라우저에서 스크립트를 줄 단위로 `new Function`에 넣어 처음 실패하는 줄을 찾았다
- **구조차가 두 기체를 통과**(②, 45.8~47.3초): 상승 경로가 두 기체 바로 위를 지났다. 제자리에서 먼저 높이 195m까지 올라간 뒤 이동하게 바꿨다

## 확인한 것

- 세 시나리오 모두 겹침 계산을 돌렸다(겹침은 추돌 순간 한 번뿐)
- 탭을 눌러 ②로 바꿨을 때 프리로드가 다시 돌지 않고 바로 재생되는 것, ②·③이 결과 화면 약 4.5초 뒤 처음부터 도는 것을 확인했다
- ②의 목격자와 "시민 신고 접수" 장면을 화면으로 봤다
