# 26-2 해커톤: SKY RESCUE — 3D 위치(X·Y·Z) 기반 구조 관제 시뮬레이션

서울 도심 상공에서 비행차량 두 대가 가볍게 추돌했을 때, **높이(Z) 정보와 자동 신고가 있느냐 없느냐**에 따라 구조가 어떻게 달라지는지를 브이월드 3D 지도 위에서 보여 주는 웹 시뮬레이션입니다.
119 상황실 화면처럼 꾸민 패널(사고 개요·3축 좌표·탑승자 생체신호·출동·2차 위험)과 함께 세 가지 시나리오가 18초씩 재생됩니다.

**2026 전문대학 연합 Career-UP AI 해커톤(주제 「미래」) 대상(1등)** 출품작입니다. 6팀 사다리, 팀장이 만들고 정리했습니다.

- **배포는 종료되었습니다.** 대회 때 올렸던 `https://educnp.mycafe24.com/team6/`는 대회 종료 후 "서비스 완료 안내" 페이지로 바뀌어, 체험용 배포본은 남아 있지 않습니다. 직접 보려면 아래 **실행**대로 로컬에서 돌리세요(PC 크롬 권장, 모바일 미대응).
- **모든 수치와 상황은 발표용 가정입니다.** 센서, 119 연계, 탑승자 생체신호는 모두 가상 데이터입니다.

## 실행

```
python -m http.server 8765        이 폴더에서 실행한 뒤
http://127.0.0.1:8765/seoul_vworld.html   크롬으로 열기
```

- `seoul_vworld.html` 위쪽의 `VWORLD_KEY`에 브이월드 API 키를 넣어야 지도가 뜹니다.
- **인터넷이 필요합니다.** 브이월드 서버(3D 지도), jQuery, Google Fonts를 받아 옵니다.
- 파일을 더블클릭(`file://`)하면 브이월드 인증이 실패할 수 있습니다. 위처럼 로컬 서버로 여세요.
- 처음 열면 "서울 3D 건물 불러오는 중"이 끝날 때까지 기다려야 합니다(프리로드, 사이트를 켤 때 한 번). 끝나면 평시 시나리오가 자동으로 반복 재생됩니다.
- 서버에 올리는 방법과 문제 대응은 `docs/운영.md`.

## 시나리오 (상단 탭)

| 탭 | 내용 | 결과 (가정) |
|---|---|---|
| ① 평시 운항 | 비행차량들이 정상 운항, 119 신고 0건, 탑승자 지표 정상. 계속 반복 | — |
| ② 높이 정보 없음 | 추돌했지만 자동 신고와 높이 정보가 없음. 지상 시민이 신고, 구조대는 지상 위주 수색 | 구조 접근 약 19분, 탑승자 1명 심정지 → 골든타임 상실 |
| ③ 3D 좌표 자동 전송 | 사고 순간 3D 좌표 자동 전송, 구조 비행차량이 위에서 접근해 `-[` 모양으로 견인 | 구조 도달 약 5분, 착륙까지 약 14분, 2차 사고 없음 |

탭을 누르면 바로 재생되고, ②·③은 결과 화면을 약 4.5초 보여 준 뒤 처음부터 반복합니다. 한 시나리오는 18초(내부 시간 54초를 3배속)입니다.

| 키·버튼 | 동작 |

## 기술 스택

순수 HTML + CSS + JavaScript 단일 파일. 지도·3D 렌더링은 **브이월드 3D 지도 API 3.0**(내장 Cesium 1.99)이 합니다. 프레임워크, 서버, DB, 애니메이션 라이브러리는 쓰지 않았습니다.
자세한 내용은 `docs/구현_이해하기.md`.
